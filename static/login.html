Admin login

The editor saves games to the GitHub repository, so it needs a GitHub token that may write to it. The token stays in this browser only.

How to create the token
  1. On GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → .
  3. Permissions → Repository permissions → Contents: Read and write (nothing else).
  4. Pick an expiry date, generate, and paste the token above.
